# Catrie

A premium frontend-only cakery showcase + booking site. React + Vite + Tailwind, deployed as a static SPA to Vercel. No backend, no accounts, no payments — all data is local and all mutations are simulated (demo mode).

## Pages

| Route | Page |
|---|---|
| `/` | Home (hero, marquee, categories, signature cakes, story, testimonials, CTA) |
| `/categories` | Category hub (4 editorial tiles with live counts) |
| `/cakes` | Catalog — filter chips, search, sort, grid, empty state (URL-synced) |
| `/cakes/:slug` | Cake detail — gallery, size/flavor selectors, booking, related |
| `/about` | Story & process |
| `/contact` | Contact + demo form |
| `/policies` | Privacy · Terms · Booking & Cancellation · Allergens |
| `/403` | Access restricted |
| `*` | 404 Not found |

## Getting started

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # type-checks then builds to dist/
npm run preview    # serve the production build locally
```

## Scripts

- `prepare-fonts` — trims self-hosted fonts into `public/fonts/` (run automatically; see `scripts/prepare-fonts.mjs`)
- `build-logo` — regenerates the outlined Kaushan wordmark/mark SVGs from the TTF (`scripts/build-logo.mjs`)
- `build-og` — composes the 1200×630 OG image from the wordmark (`scripts/build-og.mjs`)
- `process-upload` — compresses a cake's uploaded photos into the final WebP cuts and writes them to `public/images/cakes/<key>/` (`scripts/process-upload.mjs`)
- `add-photo` — appends one extra photo to an existing cake gallery (`scripts/add-photo.mjs`)

## Vercel

- Framework preset: **Vite** (or a generic SPA)
- Build command: `npm run build`
- Output directory: `dist`
- `vercel.json` adds SPA rewrites and immutable cache headers for hashed assets/fonts/images.

## Notes

- **Images**: each cake's photography lives in `public/images/cakes/<key>/` as `1.webp…4.webp` (gallery) + `cover.webp` (card), generated by `scripts/generate-cakes.mjs` — see `CREDITS.md` for the pipeline.
- **Demo mode**: `site.demoMode` in `src/config/site.ts` toggles the "nothing was sent" hints. Booking/contact are isolated behind `src/services/*` so a real API can be wired in without touching the UI.
